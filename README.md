# Shop tech management project

A Java console application.

## Tech stack

- Java
- Lombok

## Concepts covered

Collections, console input (Scanner), inheritance.

## Project structure

- `Details`: Microprocessor, Screen
- `Enumerations`: ComputerBrand, MaterialState, MicroprocessorBrand, PrinterBrand, PrinterType, ScreenBrand, ScreenType
- `Equipements`: Equipment, ListEquipments
- `PcsMgt`: Computer, Computers
- `Program`: Main
- `printersMgt`: Printer, Printers
- `smartphonesMgt`: Smartphone, Smartphones

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
